# ТБК Отчёт

Приложение для подготовки ежедневных отчётов о сварочно-монтажных работах. Оно помогает вести данные по двум сменам, считать сваренные стыки и ремонты, сохранять историю и формировать готовые отчёты в Excel и PDF.

Актуальная версия: **1.3**.

## Скачать

Готовые файлы находятся на странице [релиза v1.3](https://gitverse.ru/ddd_Volodya_bbb/TBK-Report/releases/tag/v1.3):

- `TBK-Report-v1.3-Windows.zip` — установщик для Windows x64;
- `TBK-Report-v1.3-Android.apk` — приложение для Android 6.0 и новее на устройствах ARM64;
- руководства по установке и использованию программы.

## Возможности

- ведение отчёта по первой и второй смене;
- ввод времени работы, номеров и количества стыков, ремонтов и комментариев;
- два режима расчёта: по номерам стыков или по их количеству;
- автоматическое продолжение нумерации между сменами и отчётами;
- отдельная нумерация и месячные итоги для каждого номера ГК;
- учёт начальных данных, если коллектор начали варить раньше;
- заполнение шапки отчёта и данных техников;
- добавление рукописных подписей техников;
- ведение оборудования в работе и резерве;
- список проблемных вопросов;
- сохранение незавершённого отчёта;
- история отчётов с просмотром, исправлением и удалением записей;
- расчёт дневных и нарастающих месячных итогов;
- экспорт отчётов в Excel и PDF;
- автоматический экспорт при сохранении отчёта;
- резервное копирование и перенос выбранных данных между устройствами.

## Установка

### Windows

1. Скачайте `TBK-Report-v1.3-Windows.zip` и распакуйте архив.
2. Запустите находящийся внутри файл `TBK-Report-v1.3-Setup.exe`.
3. Если Windows предупредит о приложении из неизвестного источника, выберите продолжение установки.

### Android

1. Скачайте `TBK-Report-v1.3-Android.apk`.
2. Разрешите установку приложений из используемого браузера или файлового менеджера.
3. Откройте APK и подтвердите установку. Google Play Защита может показать предупреждение, поскольку приложение распространяется вне Google Play.

Подробности приведены в [руководстве по установке](<docs/ТБК Отчёт — руководство по установке.md>).

## Для разработчиков

Проект написан на C# с использованием Avalonia и MVVM. Общая логика Windows- и Android-версий находится в `src/TbkReport.Core`.

Сборка Windows-версии:

```powershell
dotnet build src/TbkReport.Windows/TbkReport.csproj -c Release
```

Готовая программа: `src/TbkReport.Windows/bin/Release/net10.0/win-x64/TbkReport.exe`.

Сборка установщика Windows и подписанного APK выполняется отдельными сценариями из каталога `scripts`. Для выпуска подписанного APK требуется локальный ключ подписи, который в репозиторий не входит.
