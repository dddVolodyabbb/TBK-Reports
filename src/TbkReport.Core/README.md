# TbkReport.Core

Общая библиотека Windows- и Android-приложений. Содержит модели и сервисы
истории, настроек, черновика, Excel- и PDF-экспорта. Не выбирает платформенные
пути самостоятельно. Общие ViewModel редактора, смен, проблем, оборудования
и шапки также находятся здесь. Они не зависят от Avalonia и не содержат Views.
Windows и Android используют один `ReportViewModel`, поэтому расчёты,
проверки и правила черновика не расходятся.

Приложение создаёт реализацию `IAppStoragePaths` и передаёт её конструкторам
`ReportHistoryStore`, `ReportDefaultsStore` и `ReportDraftStore`. Поэтому формат
данных, атомарная запись и правила проверки остаются едиными, а Windows и
Android различаются только определением каталогов.

Windows `MainViewModel` — тонкая оболочка `ReportViewModel` с путями из своего
`Common.cs`. Android `MainViewModel` содержит тот же редактор и добавляет
выбор раздела и состояние выдвижного меню. Разметка у приложений отдельная.

- Windows: `src/TbkReport.Windows/Common.cs`, данные в `%LocalAppData%\TBK Report`
  (при первом запуске после обновления старые данные рядом с EXE копируются туда).
- Android: `src/TbkReport.Android/Common.cs`, данные в
  папке приложения `Android/data/.../files`.

Общая библиотека экспортирует в обычный файловый путь. Android-адаптер экспорта
(`src/TbkReport.Android/Platform/AndroidExportService.cs`) сначала создаёт готовый
файл во временной папке приложения, а затем копирует его через `ContentResolver`
в `Documents` или в сохранённый URI выбранной пользователем папки.

`ReportHistoryStore` держит прочитанные месячные файлы истории в памяти и
перечитывает файл только после его изменения (по времени записи и размеру).
Поэтому списки месяцев и дней, итоги и следующий номер стыка не распаковывают
всю историю заново при каждом действии пользователя.
