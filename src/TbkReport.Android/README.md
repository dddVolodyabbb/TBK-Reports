# ТБК Отчёт — Android

Самостоятельное приложение C# / Avalonia / MVVM. Не ссылается на проект
Windows `TbkReport`. Оба приложения используют общую библиотеку
`../TbkReport.Core`, в которой находятся модели, история, настройки, черновик
и экспорт.

Главный экран — редактор отчёта; при запуске открывается первая смена.
Дата отчёта остаётся над прокручиваемой формой. Кнопка с тремя горизонтальными
линиями открывает панель разделов: первая и вторая смены, а внутри «Данных
отчёта» — проблемы, оборудование, шапка и начальные данные месяца. Полосы
вкладок отсутствуют. Выбор раздела закрывает панель, сохраняя дату и ввод.

Мобильные формы используют общие `ReportViewModel`, `ShiftViewModel` и модели
данных из Core. Расчёты, проверка обязательных полей, автосохранение и
восстановление черновика, сохранение истории и постоянных данных совпадают
с Windows. Отдельный объект редактора сохраняется при переключении разделов.

Меню ⋮ содержит сохранение отчёта, экспорт, создание нового отчёта и настройки.
Новый отчёт требует подтверждения при несохранённых изменениях. Excel и PDF
используют общие экспортёры. Пункты меню имеют увеличенную область нажатия.
Во время редактирования отчёта из истории пункт «Новый отчёт» скрыт, а отмена
возвращает обычный черновик без изменения истории. В шапке можно нарисовать
подпись пальцем для каждой смены; существующая подпись открывается на
редактирование, а отмена восстанавливает исходный рисунок.
Настройки повторяют Windows-форму в вертикальной раскладке: выбор папки,
сохранение и возврат к папке по умолчанию. Изменения применяются кнопкой
«Сохранить»; системная и экранная кнопки «Назад» возвращают к первой смене.
Подписи пустых полей времени — «часы» и «минуты». Отдельного пункта «Отчёт» нет.

История использует те же данные и этапы просмотра, что Windows: месяцы и годы,
дни, затем просмотр отчёта с показателями смен, дневными и месячными итогами,
комментариями, проблемами и оборудованием. Месяцы и дни размещены вертикально,
ширина таблиц ограничена экраном, длинный текст переносится. Комментарии первой
и второй смен показаны друг под другом. Просмотр не меняет редактируемый отчёт.
Экранные кнопки и системная «Назад» возвращают от отчёта к дням, затем к месяцам
и к редактору. Открытая боковая панель закрывается раньше перехода назад.

История, `settings.json`, `draft.json` и остальные служебные данные используют
папку приложения `Android/data/com.tbkreport.android/files`. Если внешняя папка
приложения временно недоступна, Android предоставляет внутреннюю папку как
резервную. Пути Android собраны в `Common.cs`. Общие сервисы получают их через
`IAppStoragePaths`, поэтому код работы с файлами и правила сохранения не дублируются.

Экспорт по умолчанию сохраняется в `Documents/TBK Report` через MediaStore
(Android 10+). Другую папку можно выбрать системным диалогом документов.
Доступ сохраняется через bookmark StorageProvider, а bookmark и название папки —
в `settings.json`. Перед экспортом папка открывается по сохранённому bookmark;
при потере доступа приложение предлагает выбрать её заново. Для Android 6–9
нужно выбрать папку в настройках. Экспортёр создаёт временный файл в папке
приложения, а Android-слой копирует его в выбранную папку. Замена существующего
отчёта требует подтверждения; при замене через диалог документов сначала
создаётся локальная резервная копия исходного файла.

Системная кнопка или жест «Назад» сначала закрывает панель разделов, затем
отменяет открытое подтверждение нового отчёта, затем возвращает с выбранного
раздела к первой смене главного отчёта. На главном экране для выхода
нужны три нажатия за три секунды; после первых двух показывается Toast с числом
оставшихся нажатий.

Горизонтальный свайп по области раздела переключает разделы в порядке меню
(`Views/MainView.axaml.cs`). Свайп начинается после 20 dp по горизонтали, если
движение хотя бы вдвое горизонтальнее вертикального; иначе жест остаётся
прокрутке. После начала свайпа кнопка или поле под пальцем не срабатывает.
Раздел переключается, если его протянули на четверть ширины или быстро смахнули
(от 48 dp); в остальных случаях он возвращается на место. Прерванный системой
жест тоже возвращает раздел. Свайп не начинается в поле с курсором (там палец
двигает курсор и выделяет текст), при открытом редакторе подписи и не
перехватывается вторым пальцем.

Проект: `TbkReport.Android.csproj`, Android API 23+, .NET 10 / API 36.
Версии пакетов соответствуют проверочному проекту `tests/AndroidPackageCache`.
Сборка выполняется только по явной команде пользователя.
