Коллеги, привет! Выкладываю программу «ТБК Отчёт» версии 1.4 для ежедневных отчётов по сварке: две смены, стыки, ремонты, история, выгрузка в Excel и PDF. Есть версия для компьютера и для смартфона.

Скачать:
• на компьютер (Windows) — https://github.com/dddVolodyabbb/TBK-Reports/releases/download/v1.4/TBK-Report-v1.4-Setup.exe
• на смартфон (Android) — https://github.com/dddVolodyabbb/TBK-Reports/releases/download/v1.4/TBK-Report-v1.4-Android.apk

Как установить — по шагам на картинках ниже, красной рамкой обведено, куда нажать: первая картинка — для компьютера, вторая и третья — для смартфона.

Если уже стоит версия 1.3 — просто установите новую поверх, отчёты и настройки сохранятся. На всякий случай перед обновлением сделайте копию: «Параметры» → «Экспорт данных».

Подробная инструкция по работе с программой (с картинками):
https://github.com/dddVolodyabbb/TBK-Reports/releases/download/v1.4/TBK-Report-v1.4-User-Guide.pdf
