# Android Release-подпись

Файлы `tbk-report-release.keystore` и `tbk-report-release.password` образуют постоянную
подпись Android-приложения. Они исключены из Git и должны храниться вместе в
надёжной резервной копии. Без них невозможно выпустить обновление, которое
установится поверх версии с постоянной подписью.

Официальную Release-сборку создаёт `scripts/Build-AndroidRelease.ps1`. Скрипт
останавливается, если ключ или пароль отсутствуют, чтобы APK случайно не был
подписан тестовым сертификатом Android Debug.
